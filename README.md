# my-keeb

A custom 60% mechanical keyboard that I designed from scratch, sponsored by Hack Club ❤️
### Each step is also found in commits with description

## Planning the Keyboard

I started by deciding on the layout and then decided what I wanted to include. I decided to include rgb leds, a rotary encoder, and a buzzer.
Took me about 15 minutes or less

![Planning](https://github.com/Ahmedjk4/my-keeb/blob/main/photos/rx22jeb0mpx01.jpg)

## Designing the PCB

I designed the schematic and PCB in KiCad. This was one of the hardest parts because it was my first time designing a PCB.
This holy step took more than 12 hours

## Designing the Case

After finishing the PCB, I designed a 3D-printed case around it using Onshape.
Took me 6 hours because of the constrains tools always mess up when I try to move a sketch rectangle to fit the key.
![Case](https://github.com/Ahmedjk4/my-keeb/blob/main/photos/Screenshot%202026-08-12%20035022.png)

## Writing the Firmware

Finally, I wrote the keyboard firmware using RMK firmware ( didn't write it I actually edited a .toml file ) and built it on github actions, on my repo https://github.com/Ahmedjk4/custom-keyboard-firmware/

![Firmware](https://github.com/Ahmedjk4/my-keeb/blob/main/photos/Screenshot%202026-08-12%20043313.png)

## What I Learnt

I learnt a lot about PCB design, CAD, and embedded keyboard firmware.
